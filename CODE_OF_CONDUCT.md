# Code of conduct

## The standard

Be direct, be technical, be kind. Disagree with reasoning and evidence.
Assume the person on the other side is trying to build something good.

Not acceptable: harassment, personal attacks, demeaning comments, publishing
someone's private information, or any conduct that would reasonably make a
contributor feel unwelcome.

Also not acceptable here, because it damages the work: presenting numbers
you did not measure, arguing from authority instead of evidence, or
pressuring a maintainer to accept a claim without a run id.

## Scope

This applies in issues, pull requests, discussions, and any space where
someone is representing the project.

## Enforcement

Report conduct issues to the maintainers through a private GitHub security
advisory or by contacting the RightNow AI organization owners. Reports are
handled confidentially. Maintainers may warn, remove content, or ban
accounts, in proportion to the behavior.

This document is adapted in spirit from the Contributor Covenant, rewritten
to match how this project actually works.
